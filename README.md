# Portfolio Projet : Potluck Manager - Backend

Un service web qui agit comme passerelle backend dans le project potluck.  
Visiter la page de documentation API (voir lien plus bas)

### Résumé du service web
- **API**
  - REST
  - Ressources
  - Endpoints
  - Méthodes HTTP (GET, POST, PUT, DELETE)
  - Codes d'erreurs
- **Documentation**:
  - Swagger
- **Modélisation**:
  - Modèle conceptuel
  - Modèle logique
  - voir "docs/modelisation.pdf"

### Stack technique
- Langage: **Python** 3.14
- Modules principaux: **Flask** et **Flask-SQLAlchemy**
- Documentation: Swagger
