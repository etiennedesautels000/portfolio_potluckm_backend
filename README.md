# Portfolio Projet : Potluck Manager - Backend

Un service web qui agit comme passerelle backend dans le project potluck.  
Visiter la page de documentation API (voir lien plus bas)

### Résumé des ressources et actions possibles
- **Potlucks**:
  - lister tous les potlucks
  - lister 1 potluck
  - lister tous les sous-groups de 1 potluck
  - ajouter 1 potluck
  - modifier 1 potluck
  - supprimer 1 potluck
- **Subgroups**:
  - lister tous les subgroups
  - lister 1 subgroup
  - lister toutes les contributions de 1 subgroup
  - ajouter 1 subgroup
  - modifier 1 subgroup
  - supprimer 1 subgroup
- **Contributions**:
  - lister toutes les contributions
  - lister 1 contribution
  - ajouter 1 contribution
  - modifier 1 contribution
  - supprimer 1 contribution

### Stack technique
- Langage: **Python** 3.14
- Modules principaux: **Flask** et **Flask-SQLAlchemy**
